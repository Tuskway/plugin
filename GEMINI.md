# Tuskway

Tuskway is a shared plan for coding agents. This extension connects to the hosted MCP server at `https://tuskway.com/mcp`. Sign-in is OAuth in the client.

## Skills

- `comments-tuskway` applies note comments and records each one as resolved, replied, or still open.
- `draft-tickets-tuskway` turns an approved design into ticket briefs.
- `plan-tuskway` shows which tickets in one epic can start together.
- `setup-tuskway` checks the connection and workspace, then gives one next step.
- `start-epic-tuskway` opens an epic and writes the intake notes.
- `sync-design-tuskway` compares merged work with the design.
- `tackle-ticket-tuskway` implements one named ticket and records each acceptance check.
- `tracker-changes-tuskway` accounts for pending tracker edits against the current notes.
- `write-design-tuskway` proposes a technical design grounded in the repository.
